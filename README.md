# 🐳 DesktopPet - 大肥鱼桌宠

一个基于 Python + PyQt5 开发的可爱桌面宠物。她是一只爱吃白饭的蓝色大肥鱼，不仅能在你的桌面上自由漫步，还会和你互动聊天、陪你一起摸鱼！

## ✨ 核心特性

*   **🎮 丰富的交互反馈**：
    *   **单击**：戳一戳她会害羞/吐槽（“哎呀，别戳啦，会变胖的！”）。
    *   **双击**：她会贴心地报出当前时间（格式：xxxx年xx月xx日 xx:xx:xx）。
    *   **拖拽**：可以用鼠标抓起来扔出去！松开鼠标后会有真实的**重力、摩擦力和弹跳**物理效果，落地时还有专属台词。
    *   **右键**：呼出菜单，选择“退下吧，鱼鱼”即可关闭程序。
*   **🧠 智能 AI 行为**：无聊时会自己在桌面上散步，走累了会原地站立发呆，碰到屏幕边缘还会智能转身，并抱怨“碰壁了...”。
*   **💬 动态气泡系统**：使用 `QTextDocument` 进行精确排版，气泡会智能判断屏幕边界（头顶没空间时自动翻转到下方），绝不会跑出屏幕外。
*   **🎨 物理引擎**：内置简单的物理逻辑（重力、空气阻力、落地反弹），扔出去再也不用担心摔坏啦。

## 🛠️ 环境依赖

*   Python 3.7+
*   PyQt5

安装依赖：
```bash
pip install PyQt5
```

## 🚀 快速开始

### 方法一

1. 下载打包好的EXE可执行文件压缩包（**`build.zip`**）。
2. 解压后双击EXE可执行文件即可运行。（注意不要把可爱的大肥鱼图片丢弃掉哦）

### 方法二

1. 克隆或下载本项目代码。
2. 准备一张你喜欢的宠物图片，命名为 **`pet.png`**，并放在与 `desktop_pet.py` 同级的目录下。（如果没有图片，程序将无法正常运行）
3. 运行程序：
```bash
python desktop_pet.py
```

## 🎮 交互指南

| 操作 | 效果 |
| :--- | :--- |
| **鼠标左键单击** | 触发戳一戳动作，并随机说出互动台词。 |
| **鼠标左键双击** | 弹出当前系统时间，并触发小跳跃。 |
| **鼠标左键长按拖拽** | 抓起宠物，松手后会根据拖拽速度产生惯性并自由落体。 |
| **鼠标右键单击** | 弹出退出菜单（退下吧，鱼鱼）。 |

## ⚙️ 配置与自定义

你可以通过修改 `desktop_pet.py` 开头的配置参数来定制你的专属桌宠：

*   `IMAGE_PATH`：宠物图片路径（默认为 `pet.png`）。
*   `TARGET_HEIGHT`：宠物在桌面上的显示高度（默认为 250 像素）。
*   `GRAVITY` / `BOUNCE_FACTOR`：调整下落重力和弹跳力度，打造你的专属“弹簧猫/鱼”。
*   `IDLE_QUOTES`：待机时的随机台词库。
*   `SCENE_QUOTES`：点击、拖拽、落地、碰壁时的场景台词库（你可以尽情添加你喜欢的二次元语录）。
*   `TALK_INTERVAL_MIN/MAX`：待机多久后主动说话。
